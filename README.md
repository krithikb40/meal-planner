# meal-planner
Repository for meal planner program
## Project Goal

To make meal planning easier for those who want to better their health

## MVP Scope
- add and save recipes
- weekly meal plan
- grocery list
- saved data

## Future Plans
- search recipes from API
- pantry tracking
- scale recipes by serving
- nutrition/calorie information
- favorites list

## Tech Stack
- Language: Java
- Libraries: Gson (JSON), Java HttpClient
- Data Storage: JSON Files
- Data sourceL: TheMealDB API
- Tools: IntelliJ, Terminal, Git/Github
